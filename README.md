# CodeStart IX

Site static pentru recapitularea materiei de C++ din clasa a IX-a.

## Pornire

Deschide `index.html` într-un browser. Nu sunt necesare dependințe sau un server local.

## Publicare

Pentru adresa principală `https://danabotofei.github.io/`, repository-ul GitHub trebuie să se numească exact `DanaBotofei.github.io`, iar GitHub Pages trebuie configurat pe branch-ul `main`, folderul `/ (root)`.

## Conținut

- 7 capitole și 28 de sublecții, de la algoritmi și sintaxă până la vectori, matrice și string-uri;
- fiecare capitol are obiective, sinteză teoretică și checklist;
- pentru fiecare sublecție: explicații, idei-cheie, exemplu de cod, exercițiu rezolvat și trei exerciții de fixare;
- navigare pe capitole expandabile și marcarea lecțiilor finalizate, salvată în `localStorage`;
- quiz interactiv cu 6 întrebări, scor și cel mai bun rezultat;
- comutator pentru tema luminoasă/întunecată;
- layout responsive pentru telefon și desktop.
